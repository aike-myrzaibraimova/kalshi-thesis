# Prediction markets vs. forecasting models: CPI, fed funds rate, and S&P 500

Code and data for my Master's thesis comparing Kalshi prediction-market
forecasts with statistical and machine-learning models and with market-based
benchmarks (Cleveland Fed nowcast, fed funds futures, E-mini S&P 500 futures).

- [`Reproducibility/`](Reproducibility/): the full analysis pipeline; start with its [README](Reproducibility/README.md)
- [`Thesis/`](Thesis/): LaTeX source, bibliography, figures, and the thesis PDF

Licensed LSEG data is not included in this repository; see
[Reproducibility/README.md](Reproducibility/README.md#lseg-data-not-included-in-this-public-version).
